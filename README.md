## Project Description

GroupDNA is a WhatsApp Chat Analytics System that analyzes exported WhatsApp chat files and generates meaningful insights about group conversations.

The project is developed using Python Fundamentals and NumPy without relying on advanced data analysis libraries.

---

## Features

- Chat Parsing
- Group Overview
- Most Active Day
- Most Active Hour
- Activity Heatmap
- Top Frequently Used Words
- Response Analysis
- Silent Streak Detection
- Personality Archetype Detection
- Final Analytics Report
